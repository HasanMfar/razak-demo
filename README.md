## 🌟 ویژگی‌های برجسته رازک:

- 💎 **طراحی لوکس شیشه‌ای (Glassmorphism):** رابط کاربری فوق‌مدرن و ترند روز بدون ریالی هزینه سنگین تغییر قالب.
- ⚡ **حجم ناچیز و سرعت سرسام‌آور:** کمتر از ۳۵ کیلوبایت، کدنویسی ۱۰۰٪ وانیلا بدون جی‌کوئری (Pure Vanilla JS).
- 🚀 **ورود یک‌کلیکه با اکانت گوگل (One-Tap & Google Sign-In):** ورود فوق‌سریع بدون نیاز به وارد کردن شماره یا رمز عبور.
- 📱 **سازگار با تمام درگاه‌های معتبر پیامکی:** کاوه‌نگار، فراز اس‌ام‌اس، SMS.ir، ملی‌پیامک، قاصدک، مگفا و پترن‌های خدماتی سریع.
- 🤖 **ارسال ۱۰۰٪ رایگان با پیام‌رسان‌ها:** پشتیبانی بومی از ربات‌های پیام‌رسان بله و ایتا برای حذف هزینه‌های پیامکی.
- 🛡️ **امنیت ضد اتک و ضد تقلب:** کپچای داخلی ریاضی ضد ربات، ریت لیمیت پیشرفته و لاگ امنیتی ورودها.
- 🧩 **سازگار با تمام صفحه‌سازها:** ویجت اختصاصی المنتور، بلوک مدرن گوتنبرگ و شورت‌کدهای منعطف.
