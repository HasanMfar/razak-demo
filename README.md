# رازک — پیش‌نمایش زندهٔ پنجره ورود

این صفحه، دموی تعاملی افزونهٔ «رازک» است: همان پنجره‌ای که بعد از نصب روی سایت شما می‌نشیند — با تفاوت اینکه اینجا می‌توانید استایل، رنگ برند، پس‌زمینه و گزینه‌هایش را همین‌جا امتحان کنید.

- **دموی زنده:** https://hasanmfar.github.io/razak-demo/
- **صفحهٔ محصول:** https://www.rtl-theme.com

افزونهٔ رازک ورود و ثبت‌نام با شماره موبایل (کد یکبارمصرف)، ورود با حساب گوگل، تایید دومرحله‌ای پیامکی و کپچای داخلی را به وردپرس و ووکامرس اضافه می‌کند.

*این ریپو فقط دمو را نگه می‌دارد؛ سورس افزونه در ریپوی خصوصی نگهداری می‌شود.*
